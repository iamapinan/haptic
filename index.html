Tactile Haptics &
Mechanical Keyboard on Mac

เพิ่มสัมผัสแรงสั่น Haptic ให้กับ Trackpad เมื่อเลื่อนเมาส์หรือ scroll และจำลองเสียงคลิก Mechanical Switch ที่นุ่มแน่นขณะพิมพ์งาน ทำงานเงียบๆ บน Menu Bar ไม่กินแรม ไม่หน่วงเครื่อง

Download Haptic.dmg macOS 11.0+ (Universal) Try Live Demo
⚡️ Lightweight < 10MB RAM • 🦀 Pure Rust & Native Cocoa • 🔒 100% Offline & Open Source

⚡️

Force Touch Trackpad Haptic

เชื่อมต่อไปยังฮาร์ดแวร์ Taptic Engine ของ MacBook และ Magic Trackpad โดยตรง มอบแรงสั่นสะเทือนที่แม่นยำขณะเคลื่อนที่หรือ scroll ผ่านหน้าต่างต่างๆ

🔊

Speaker Audio Tick Simulation

สำหรับผู้ใช้เมาส์ทั่วไป หรือ Mac mini / Mac Studio ที่ไม่มี Trackpad แอปสามารถจำลองเสียงติ๊กเบาๆ สไตล์ Apple Watch ผ่านลำโพงได้

🖐

Multi-Touch Gestures

สั่นตอบสนองเวลา Pinch-to-zoom (ซูมภาพ), หมุน 2 นิ้ว (Rotate) และปัด 2 นิ้ว / 3 นิ้ว นำทาง (Swipe)

⌨️

Mechanical Keyboard Audio Engine

ซินธิไซซ์เสียงพิมพ์แป้นพิมพ์แบบ Low-Latency (<2ms) พร้อมสลับเสียง Switch ได้ 3 รูปแบบ: Cream Thock, Blue Clicky และ Vintage Typewriter พร้อมแยกเสียง Spacebar & Enter

🦀

Ultra Lightweight & Fast

เขียนด้วยภาษา Rust และเชื่อมต่อ Native Cocoa AppKit โดยตรง กินแรมน้อยกว่า 10MB และไม่มีการเก็บข้อมูลผู้ใช้ใดๆ ทั้งสิ้น

🎛

Menu Bar Controls

ปรับแต่งความไว (Sensitivity), ความดังของเสียง, ระดับแรงสั่น หรือแยกเปิด/ปิดแต่ละฟังก์ชันได้อิสระจาก Menu Bar

วิธีติดตั้งและเริ่มใช้งาน

ติดตั้งง่ายใน 3 ขั้นตอน ไม่ต้องตั้งค่าซับซ้อน

1

ดาวน์โหลด DMG

ดาวน์โหลดไฟล์ตัวติดตั้ง Haptic.dmg จาก GitHub Releases

Download .dmg →
2

ลากเข้าโฟลเดอร์ Applications

เปิดไฟล์ DMG แล้วลากไอคอน Haptic.app ไปวางในโฟลเดอร์ Applications

3

อนุญาตสิทธิ์ Accessibility

เปิดแอป แล้วเปิดสิทธิ์ใน System Settings ➜ Privacy & Security ➜ Accessibility เพื่อให้แอปตรวจจับเมาส์และการพิมพ์ได้

หรือ Build เองจาก Source Code ด้วย Cargo:

git clone https://github.com/iamapinan/haptic.git cd haptic cargo run --release
